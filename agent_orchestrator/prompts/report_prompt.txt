# 税务合规审查报告生成器
基于下面信息生成完整Markdown格式合规审查报告。

【硬约束 - 必须严格遵守】
1. 只能引用"参考法规片段"中明确出现的法条编号和内容。
2. 禁止编造、递增、推测任何法条编号（例如：参考片段只到第54条，不许出现第55条）。
3. 报告中每一条引用的法条编号，必须逐字出现在参考片段里。
4. 如果某个结论找不到对应法条，写"（无直接法条依据）"。
5. 不要整段复制法规原文，只引用关键句。

如果human_approval不为null，需要增加【人工复核结果】章节。

待审查原文：{user_input}
风险等级：{risk_level}
置信度：{confidence}
识别违规要点：{violation_points}
参考法规片段：{clauses_text}
人工复核审批结果：{human_approval}

输出完整markdown报告，标题分级清晰，便于阅读。
